# My English Adventure

個人英文學習網頁 App（純 HTML／CSS／Vanilla JS，不使用任何 API 或外部程式庫）。

目前版本：**2.1.0（全新介面、課程補齊、半長模擬考、預估分數與弱點分析、聽力訓練、生字本）**

- P1：基礎架構、首頁、導覽、資料庫
- P2：程度診斷、課程、單字圖書館、單字複習、依精神狀態的今日安排
- P3：遊戲樂園（圖字配對、單字快打、拼字工坊）、錯題百科與錯題重練、題庫擴充為 6 堂課 24 個單字
- P4：間隔複習排程（1、3、7、14、30 天）、經驗值與等級、依精神狀態調整的每日任務、每日挑戰、13 個成就、學習數據分析
- P5：PWA（可加入主畫面）、離線使用、音檔離線播放、JSON 備份與還原、新版本更新提示
- 2.0：世界地圖依多益考試架構分成 11 個世界——基礎打底（單字、文法、發音）→ 聽力 Part 1～4 → 閱讀 Part 5～7 → 模擬考殿堂，共 24 堂課
- 2.0：多益單字庫 4107 字（NGSL 常用字 2848＋TSL 多益專用字 1259），每字都有中文、詞性、美式音標、例句與翻譯、單字與例句發音
  - 系列：🔥 多益高頻 500（多益出現頻率最高的字，最先背）、📗 多益必備字、📘📙📕 基礎常用 1～3；每 20 字一個單元（認字＋小測驗，學完自動排進複習）
  - 依多益情境分類：辦公室、會議活動、人事職涯、財務金融、行銷業務、旅遊出差、餐飲、購物消費、製造物流、交通、房屋設施、健康醫療
  - 首頁「今日安排」會自動排入下一個單字單元；單字頁可以用英文或中文查字
- 2.1：全新高級感介面（沉浸式作答、答對特效與連對、星等完成畫面、升級慶祝卡），不使用音效
- 2.1：文法課補齊 11 堂（詞性判斷、現在／過去式、進行式與未來式、介系詞、連接詞、關係代名詞、被動語態、比較級），每課 8 個部分
- 2.1：多益 Part 1～7 每個 Part 約 5 堂課，聽力加入英式口音；兩回半長模擬考（各 100 題、限時 60 分鐘），交卷後顯示預估多益分數
- 2.1：單字卡加上「多益常考意思、詞性變化、常見搭配、同義字、易混淆字」（多益高頻 500 中的 329 字）；新題型：聽音選答、例句填空、聽音拼字
- 2.1：我的生字本（收藏單字集中練習）、錯誤選項逐一解析、Part 7 限時作答（每題建議 60 秒）、聽力訓練（0.8x／1x、聽寫、跟讀錄音）、學習分析的弱點分析（依 Part 和文法點）
- 約 8,900 個英文音檔，全部離線可播放（單字庫的音檔第一次播放時下載，也可以在設定頁一次下載）

單字表來源：NGSL 1.01 與 TSL 1.1（Browne, C. & Culligan, B.，[CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)，https://www.newgeneralservicelist.com/）。中文解釋、例句與發音為本專案自製；單字庫資料（`data/vocab/bank-*.json`、`dev/bank_src/`）依同樣的 CC BY-SA 4.0 授權。

## 本機執行

ES Modules 不能用 `file://` 開啟，請用本機伺服器：

```bash
cd my-english-adventure
python3 -m http.server 8000
# 開啟 http://localhost:8000/
```

自動測試：`http://localhost:8000/tests/`

## 部署到 GitHub Pages

1. 在 GitHub 建立新的 repository（例如 `my-english-adventure`），設為 Public。
2. 把這個資料夾內的全部檔案上傳到 repository 根目錄（`index.html` 必須在最外層）。
3. 進入 Settings → Pages → Build and deployment → Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 Save。
4. 等 1–2 分鐘，網址會是 `https://<帳號>.github.io/my-english-adventure/`。
5. 手機打開 `.../tests/` 確認測試全數通過。

## 單檔版（my-english-adventure.html）

- 一個 HTML 檔就包含全部程式、教材、圖片和課程音檔，下載後直接用瀏覽器打開即可，不需要網路。
- 單字庫的 8000 多個音檔太大，單檔版只放單字庫的文字（沒有發音按鈕）；要聽單字庫發音請用 GitHub Pages 版。
- 學習資料存在「打開它的那個瀏覽器」裡；換裝置請用「設定 → 備份與還原」。
- 單檔版沒有「加入主畫面後自動更新」的功能；想要手機 App 般的體驗，請用完整專案部署到 GitHub Pages。

## 教材

- `data/catalog.json`：教材清單與版本號（`build_bank.py` 會依教材內容自動產生 `contentVersion`）。
- 單字進階欄位：`dev/bank_src/extra-*.txt`（一行一字：`英文|詞性變化|常見搭配|同義字|易混淆字|多益常考意思`）。
- 2.1 新增課程寫在 `dev/content_v21.py`（文法）、`content_v21_toeic.py`（Part 1～7）、`content_v21_mock.py`（半長模擬考），由 `build_content.py` 一起產生。
- 多益單字庫：在 `dev/bank_src/*.txt` 編輯（一行一字：`英文|詞性|中文|情境|例句|例句翻譯[|音標]`），再執行 `python3 dev/build_bank.py .` 產生 `data/vocab/bank-*.json` 與 `data/series.json`。
- `data/vocab/*.json`：單字；`data/lessons/*.json`：課程；`data/diagnosis.json`：診斷題。
- `assets/img/words/*.svg`：單字插畫。
- `assets/audio/`：發音與聽力音檔（見 `assets/audio/README.md`）。
- `assets/img/scenes/*.svg`：多益 Part 1 照片題的情境圖。
- 打開 `tests/` 會自動檢查教材：答案是否唯一、圖片是否存在、文法課是否包含 8 個部分等。

## 離線與更新

- 用 HTTPS（GitHub Pages）開啟一次後，App 就會存到手機，之後沒有網路也能開啟、上課、玩遊戲。
- 發音音檔：第一次播放時自動存到手機；也可以在「設定 → 離線使用」一次下載全部。
- 發布新版本時，App 會顯示「有新版本可以更新」，按下才會切換，學習資料完整保留。
- 開發者注意：新增或改名程式、教材、圖片檔後，要重新產生 `sw.js` 裡的離線清單並更新版本號（音檔不在清單內，不受影響）。

## 資料保存說明

- 學習資料存在瀏覽器的 IndexedDB，設定存在 localStorage。
- GitHub Pages 只提供靜態網頁，**沒有後端、沒有跨裝置同步、沒有雲端備份**。
- 「設定 → 備份與還原」可以匯出 JSON 備份檔（下載到這台裝置），換手機時用它還原。還原前會顯示摘要並再次確認。

## 資料庫版本規則

`js/db.js` 的 `MIGRATIONS` 每個版本一個函式，只能新增或轉換資料，不得刪除使用者資料。
升級時把 `DB_VERSION` +1 並新增對應遷移。
