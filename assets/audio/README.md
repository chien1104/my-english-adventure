# 音檔

全部 206 個英文音檔都已附上，App 會自動使用，不需要另外準備。

- `words/`：單字發音（40 個）
- `sentences/`：單字例句（40 個）
- `phonics/`：自然發音單字
- `lessons/`：課程例句、對話、短文朗讀、聽力題
- `toeic/`：多益 Part 1～4 與模擬考聽力

## 來源與檢查

- 由開源語音模型 Kokoro（Apache 2.0 授權，美式／英式發音）離線產生，沒有使用任何線上 API。
- 每個檔案都經過自動檢查：句子用語音辨識比對原文；單字比對語音模型的音素和課本上的音標。
- 稱謂（Ms.、Mr.）會唸成完整的字；畫面上仍顯示縮寫。

## 想換成真人錄音

用相同檔名覆蓋即可，例如把 `words/apple.mp3` 換成自己錄的檔案。格式建議：MP3、單聲道、前後留白不超過 0.3 秒。
